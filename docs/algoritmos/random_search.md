# Random Search (búsqueda aleatoria)

> Pendiente.

## 1. Identificación
- **Método básico:** búsqueda aleatoria pura.
- **Clase en MEALPY:** no existe en MEALPY 3.0.3.
- **Justificación de su inclusión:** referencia de exploración pura; cualquier metaheurística debería superarla. Su uso como algoritmo externo es la excepción acordada con el Dr. Marrero.

## 2. Idea del método
En cada evaluación genera un punto uniforme en todo el dominio y guarda el mejor encontrado. No usa información de evaluaciones anteriores.
